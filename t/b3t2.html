EXAMEN

Transpilador (source-to-source compiler)

Traduce código fuente de un lenguaje a otro de nivel similar. No es un híbrido entre compilador e intérprete. Ejemplos: TypeScript → JavaScript, Babel (JavaScript moderno → antiguo).

IMPORTANTE

Bytecode y generaciones

Bytecode: código intermedio que no es código máquina ni código fuente; se genera al compilar Java (.class) y lo interpreta la máquina virtual (JVM) → portabilidad. Generaciones: 1GL = código máquina binario · 2GL = ensamblador · 3GL = C, C++, Java, Python…

2. Representación de tipos de datos

Tipo básico (primitivo)Descripción
Entero (int)Sin decimales; tamaño según lenguaje (short, long, long long)
Real (float, double)Con parte decimal: float = menos precisión y memoria; double = mayor precisión (científico)
Carácter (char)Un carácter; se guarda como código numérico (ASCII/Unicode); normalmente 1 byte
Booleano (bool)true/false; 1 bit o 1 byte
EstructuraDescripción
Cadena (string)Secuencia de caracteres; concatenación, búsqueda, subcadenas
Array / vectorColección ordenada de elementos del mismo tipo, acceso por índice; fijo o dinámico (int edades[3] = {18,25,30};)
Registro / structCampos de distinto tipo bajo un nombre (struct Alumno {char nombre[20]; int edad; float nota;})
Dinámicas avanzadasListas enlazadas, pilas (LIFO), colas (FIFO), árboles (BD, compiladores, sistemas de archivos), grafos (redes, mapas)
Diccionario (mapa, tabla hash)Pares clave-valor, sin orden garantizado; en Java TreeMap ordena las claves

Sistemas binario y hexadecimal

  • Binario (base 2): solo 0 y 1 (bits); cada posición = potencia de 2 (2⁰, 2¹…) desde la derecha. Tabla: 512, 256, 128, 64, 32, 16, 8, 4, 2, 1. Ej.: decimal 5 → 101; binario 1010 → 8 + 2 = 10.
IMPORTANTE

Unidades de información

Bit: unidad mínima (0 o 1). Byte: 8 bits, unidad básica de almacenamiento; 256 valores (0-255). Nibble: 4 bits; muy usado en hexadecimal.

  • Hexadecimal (base 16): dígitos 0-9 y A-F (10-15); 1 dígito hexadecimal = 1 nibble (4 bits). Se usa en direcciones de memoria, colores HTML/CSS (#FF0000 = rojo) y códigos de caracteres.
ConversiónMétodo
Decimal → hexadecimal (opción 1)Divisiones sucesivas entre 16 y tomar los restos
Decimal → hexadecimal (opción 2)Pasar a binario, agrupar de 4 en 4 y buscar equivalencia (175 = 1010 1111 = AF)
Hexadecimal → decimalCada cifra a binario y luego binario → decimal
  • Ejemplos: 10 → A · 255 → FF · 11111111 → FF.

5. Bucles y recursividad

BucleCuándoRasgos
forNúmero exacto de repeticiones conocidoTres partes: inicialización, condición, actualización
whileMientras se cumpla la condiciónLa condición se evalúa antes del cuerpo (puede no ejecutarse nunca)
do…whileIgual que whileLa condición se evalúa al final: el bloque se ejecuta al menos una vez
  • Recursividad: la función se llama a sí misma. Necesita caso base (condición de parada) — sin él hay desbordamiento de pila (stack overflow) — y llamada recursiva con un valor más cercano al caso base.
  • Ejemplo: factorial(n): si n == 0 devuelve 1 (caso base); si no, n * factorial(n-1).

EXAMEN

Variables locales y globales

Las variables son espacios en memoria con un nombre; su ámbito (visibilidad) depende de dónde se declaran. Hay dos tipos principales según su ámbito: LOCALES y GLOBALES.

AspectoLocalesGlobales
DeclaraciónDentro de una función o bloqueFuera de cualquier función
ÁmbitoSu función o bloqueTodo el programa
Tiempo de vidaMientras se ejecuta la función (se crean al entrar y se eliminan al salir)Toda la ejecución
Acceso desde otras funcionesNoSí
Riesgo de interferenciasBajoAlto
UsoDatos temporalesDatos compartidos
  • Sobrecarga de funciones (overloading): misma función con distinto número o tipo de parámetros (C++: int sumar(int,int) y float sumar(float,float)). No confundir con sobrescritura (override): redefinir funciones heredadas en POO.

7. Vectores y registros

  • Array: valores del mismo tipo en posiciones consecutivas de memoria; índice desde 0 (array[2]).
  • Multidimensional: array de arrays; el más común es el bidimensional (filas × columnas): matriz[fila][columna]; también 3D (array3D[x][y][z]). Los índices deben estar en rango; los arrays estáticos fijan su tamaño en compilación.
  • Registro / struct / record: campos de tipos distintos bajo un mismo nombre; acceso con el operador punto (alumno.nombre).
ContiguasNo contiguas
AlmacenamientoPosiciones consecutivas de memoriaElementos unidos por referencias o punteros
VentajasAcceso directo O(1) por índiceFlexibilidad en inserción y eliminación
InconvenientesTamaño generalmente fijoMás tiempo de acceso y gestión de memoria más compleja
EjemplosArrays, cadenas (arrays de caracteres), multidimensionales (row-major o column-major)Listas enlazadas, árboles, grafos
EXAMEN

  • Cola simple (FIFO): inserción al final, eliminación al inicio; no admite posiciones intermedias.
EXAMEN

Bicola (double-ended queue o deque)

Inserciones y eliminaciones por ambos extremos; más flexible que la cola simple. Cola de salida restringida: inserciones por ambos extremos y eliminaciones solo por uno. Cola de entrada restringida: inserciones solo por un extremo y eliminaciones por ambos.

  • Cola de prioridad: sale primero el de mayor prioridad, sin importar el orden de inserción. Cola circular: reutiliza el espacio libre al principio del array; dos punteros (inicio y fin) que se mueven circularmente.
EXAMEN

FIFO — Cola (Queue)

El primer elemento en entrar es el primero en salir (línea de espera). Estructura típica: cola. Operaciones: enqueue() = insertar al final; dequeue() = eliminar del frente.

Método de accesoDescripción
LIFO — PilaÚltimo en entrar, primero en salir (pila de platos); push() inserta en el tope, pop() elimina del tope
Directo o aleatorioAcceso a cualquier elemento sin recorrer otros; requiere estructuras contiguas (arrays); mediante índices
SecuencialElemento a elemento, en orden; listas enlazadas y archivos secuenciales
Algoritmo de ordenaciónIdea
Bubble SortComparar e intercambiar adyacentes si están mal ordenados
Selection SortBuscar el menor y colocarlo en la primera posición; repetir
Insertion SortColocar cada elemento en su lugar entre los ya ordenados

7.3 Árboles binarios

  • Estructura jerárquica dinámica no lineal; cada nodo tiene como máximo dos hijos (subárbol izquierdo y derecho). Recorridos: en profundidad (DFS): preorden, inorden, postorden; en amplitud (BFS): por niveles usando una cola.
  • Grado del árbol = máximo de hijos por nodo (en un binario, 2). No confundir con altura del árbol (niveles hasta la hoja más profunda) ni grado de un nodo (hijos de ese nodo).
RecorridoOrdenUso
Preordenraíz → izquierdo → derechoCopiar árboles, expresiones prefijas
Inordenizquierdo → raíz → derechoEn un ABB devuelve los datos ordenados ascendentemente
Postordenizquierdo → derecho → raízEliminar árboles, expresiones postfijas (notación polaca inversa)
  • Ejemplo (A; B, C; D, E, F): Preorden A,B,D,E,C,F · Inorden D,B,E,A,C,F · Postorden D,E,B,F,C,A.
