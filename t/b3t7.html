1. Introducción a las aplicaciones web

  • Aplicación web: programa accesible desde un navegador, ejecutado en una arquitectura distribuida, sin instalar software local. Se diferencia de una página estática en la interacción, el procesamiento dinámico, la persistencia en BD y la integración con otros sistemas (pasarelas de pago, autenticación, APIs).
EtapaCaracterísticas
Web 1.0 – estática (años 90)HTML estático, sin interacción; contenido fijo, consulta unidireccional; cambios manuales en los archivos
Web 2.0 – dinámica e interactiva (años 2000)Lenguajes de servidor (PHP, ASP, JSP); JavaScript y AJAX (actualizar partes sin recargar); usuario participativo (comentarios, perfiles)
Web 3.0 – semántica (actualidad)Estructura semántica de datos, interoperabilidad, automatización; APIs REST, ontologías, metadatos, IA; apps complejas como las de escritorio; PWA, apps híbridas, WebAssembly
Cliente (front-end)Servidor (back-end)
Qué esNavegador; interfaz con el usuarioProcesa las peticiones
HaceSolicita recursos por HTTP/HTTPS; interpreta HTML, CSS, JavaScript; lógica local (validaciones de formularios)Lógica de negocio; accede a BD y servicios externos; responde con HTML completo o datos (JSON, XML)
LenguajesHTML, CSS, JavaScriptPHP, Java, C#, Python, Node.js
  • Modelo de ejecución: (1) el usuario accede a una URL → (2) el navegador hace una petición HTTP → (3) el servidor ejecuta el código (p. ej. consulta BD) y genera la respuesta → (4) la respuesta (HTML/JSON/XML) se envía y se presenta → (5) el usuario interactúa (formularios, botones) y genera nuevas peticiones o acciones locales con JS.
Arquitectura avanzadaDescripción
Multitier (multicapa)Separa presentación, lógica de negocio y acceso a datos
SPA (Single Page Application)Toda la lógica en el cliente; el servidor solo proporciona datos
PWA (Progressive Web App)Uso sin conexión, notificaciones y capacidades de apps nativas

4.3 CSS (Cascading Style Sheets)

  • Define la presentación visual de HTML (colores, tamaños, márgenes, fuentes, posiciones) y separa contenido y presentación. Regla: selector { propiedad: valor; }.

4.3.1 Especificidad de selectores

  • Mecanismo por el que el navegador decide qué regla aplica cuando varias afectan al mismo elemento. Formato (ID – clases/pseudo-clases – etiquetas/pseudo-elementos).
SelectorEspecificidad
Etiqueta0-0-1
Clase, pseudo-clase0-1-0
ID1-0-0
Estilo en línea1-0-0-0
EjemploCálculo
input:requiredinput (0-0-1) + :required pseudo-clase (0-1-0) = 0-1-1
#contenido p1-0-1
  • Misma especificidad: gana la regla que aparece más abajo en la hoja (la más reciente). Selectores combinados suman especificidad. El comodín * tiene la menor prioridad. !important fuerza la regla aunque otra tenga más especificidad (no abusar).

4.6 Bootstrap

  • Framework front-end open source para interfaces responsivas rápidas. Incluye CSS predefinido, sistema de rejilla (grid), clases utilitarias (.text-center, .bg-primary, .mt-3), componentes (.btn, .form-control, navbars, tarjetas, alertas, modales) y JavaScript básico (desplegables, carruseles, pestañas). Es mobile-first.
